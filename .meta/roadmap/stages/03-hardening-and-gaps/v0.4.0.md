## Objective
Harden the library against real-world `.pptx` files. The current test corpus is
mostly synthetic (cxml-built fixtures and the bundled default template). This
milestone introduces a corpus of Microsoft-PowerPoint-authored files, drives
round-trip tests through them, and fixes the edge cases that surface.

## Goals
- Curate a corpus of representative real-world `.pptx` files in
  `tests/test_files/real_world/` (10–20 files spanning charts, tables,
  effects, sections, comments, 3D, transitions present-but-ignored).
- Add a round-trip test that opens, modifies one well-defined property, saves,
  reopens, and asserts. Parameterize across the corpus.
- Implement the one known code-level gap: `GraphicFrame.shadow` (currently
  `NotImplementedError`).
- Audit `raise` sites: replace remaining bare `ValueError` / `TypeError` in
  user-facing modules with the domain exceptions from `pptx/exc.py`; add
  consistent message format (`{what} must be {expected}, got {actual}`).
- Property-based fuzz tests (Hypothesis) on key OXML simple-type converters
  in `pptx/oxml/simpletypes.py`.
- Catch and report (via a clear exception) any unsupported elements
  encountered during load, rather than silently dropping them on save.

## Dependencies
- `v0.2.0` MANIFEST resync — so we know what is genuinely missing vs.
  documented-as-missing-but-implemented.

## Out of scope
- Adding new public API. This is a defensive / correctness pass.
- Performance work — that is `v0.6.0`'s focus, even if profiling falls out of
  fuzz-test debugging.
- Authoring support for transitions / animations (read-only access is
  `v0.5.0`).

## Objectives / acceptance
- New `tests/test_real_world_roundtrip.py` parameterized over the corpus —
  every file opens, mutates, saves, reopens without raising.
- `pytest --cov=pptx` shows no decrease vs. `v0.2.0`.
- Hypothesis tests for `simpletypes` pass with `--hypothesis-show-statistics`
  showing meaningful example diversity.
- Manual smoke: open three round-tripped corpus files in PowerPoint /
  LibreOffice and visually confirm they render unchanged.
