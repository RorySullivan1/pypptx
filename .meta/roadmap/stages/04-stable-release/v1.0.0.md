# version: v1.0.0
status: planned
theme: API Freeze, Comprehensive Docs, SemVer Commitment
branch: v1.0.0
previous: v0.7.0

## Objective
Ship a stable, documented, semver-committed `1.0` release. Everything between
`v0.2.0` and `v0.7.0` is foundation work — this milestone is about declaring
the public surface stable, publishing the reference docs, and committing to
backwards-compatibility going forward.

## Goals
- Public API audit — every public symbol (exported from `pptx.*`) reviewed
  for naming, return types, and exception contract. Items not intended to be
  public are renamed with a leading underscore.
- Deprecation policy — document the support window for any pre-1.0 names
  that get renamed, with `DeprecationWarning` shims for at least one minor
  release.
- Sphinx docs published — the scaffold from `v0.2.0` is now filled in with
  generated API reference, narrative guides per area (slides, shapes, text,
  charts, effects, theme), and the 14+ runnable examples linked inline.
- `CHANGELOG.md` with entries back to `v0.1.0`, formatted for
  [Keep a Changelog](https://keepachangelog.com/) conventions.
- Migration guide for users coming from upstream `python-pptx` —
  highlight name changes, new enums, expanded chart coverage, exception
  hierarchy.
- Performance benchmark suite from `v0.6.0` becomes a CI gate — regressions
  beyond a documented threshold block release.
- `pyproject.toml` bumped to `1.0.0`; SemVer policy stated in README.

## Dependencies
- All of `v0.2.0` through `v0.7.0` must be on `main`. This is a release
  milestone, not a feature milestone.

## Out of scope
- New features. Any new public API must land in a `v0.x` first and bake.
- Breaking changes beyond the deprecation policy. If a rename is truly
  required, ship a deprecated alias and remove it in `v1.x` per policy.
- Multi-language docs (English only at 1.0). Translation belongs to post-1.0
  community contribution.

## Objectives / acceptance
- Full suite green (`pytest -q`), coverage at or above the `v0.7.0` mark.
- Real-world corpus round-trip from `v0.4.0` runs as a release gate.
- Docs build clean (`make html`) with no warnings.
- `pip install pypptx==1.0.0rc1` into a fresh venv and run every example
  script end-to-end on a smoke matrix (Python 3.9 / 3.10 / 3.11 / 3.12).
- Manual review of the migration guide by at least one downstream user.
