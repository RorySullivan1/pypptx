## Gotchas & dead ends
- Validate chart XML with the ISO 29500 XSD at
  `/mnt/skills/public/pptx/scripts/office/schemas/ISO-IEC29500-4_2016/dml-chart.xsd` (strip `mc:` blocks first).
- `c:axId`/`c:crossAx` are `xs:unsignedInt`: the 2D bar/area writers' NEGATIVE axis ids are schema-invalid
  (pre-existing; PowerPoint tolerates them). New 3D writers use positive ids. Not changed in the 2D writers.
- `c:line3DChart` requires exactly 3 axIds, so 3D line always has a series axis.
- Pyright infers un-annotated `@property` string returns as `Literal[...]`, so subclass overrides error —
