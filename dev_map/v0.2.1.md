# v0.2.1 — Example Scripts for Under-Demonstrated Areas

**Branch:** `v0.2.1`
**Previous:** `v0.2.0`
**Status:** Planned

## Objective

Give downstream readers a runnable demonstration of every major feature area
that lacks one today. After v0.2.0 the documentation is accurate; this
milestone makes the surface *learnable* — every feature group named in the
MANIFEST has at least one example script that writes a `.pptx`, re-opens it,
and asserts the round trip survived.

## Enhancements / Fixes

- `examples/chart_trendlines_error_bars.py` — series with trendlines (linear,
  polynomial, moving-average) and error bars (fixed, percent, custom).
- `examples/chart_secondary_axis.py` — combo chart via
  `Chart.add_plot(plot_type, use_secondary_axis=True)`; verify both axes
  survive round-trip.
- `examples/chart_3d_view.py` — 3D view rotation, perspective, depth percent;
  floor / side wall / back wall formatting.
- `examples/custom_slide_master_walk.py` — read-only walk of master → layout
  → slide placeholder inheritance, printing the resolved properties at each
  level.
- `examples/picture_effects.py` — brightness, contrast, grayscale,
  transparency color round-trip.
- `examples/sections_tags_custom_props.py` — collapse the existing
  `comments_and_metadata.py` coverage gap: build a presentation with named
  sections, slide and shape tags, and typed custom document properties.
- Update `README.md` "Examples" table to list the new scripts.
- Reference relevant `internal_docs/MANIFEST.md` "Implemented Features"
  subsections from each example's module docstring so a reader can navigate
  back to the canonical inventory.

## Dependencies

- `v0.2.0` merged so the MANIFEST entries referenced from example docstrings
  point at stable headings.

## Out of Scope for this Version

- New public API. If an example reveals a real API gap, file it for
  `v0.3.0`; do **not** patch the API on this branch.
- Docstring audit and Sphinx scaffold — deferred to `v0.2.2`.
- Any change to the existing `examples/` scripts beyond mechanical README
  cross-linking.

## Test Plan

- Every new example script runs end-to-end via `python examples/<name>.py`
  and produces a `.pptx` that re-opens via `Presentation(...)` without
  raising.
- Each script asserts (with bare `assert` statements) that the round-tripped
  values match what was written — not just that the file opens.
- `pytest -q` remains green.
- Manual: `ls examples/` and the README "Examples" table list the same
  files.
