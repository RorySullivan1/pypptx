# v0.2.0 — Documentation & MANIFEST Resync

**Branch:** `v0.2.0`
**Previous:** `v0.1.0`
**Status:** In Progress

## Objective

Bring the project's user-facing and internal documentation back in sync with
the actual implementation state. Through v0.1.0 the codebase shipped almost
all of `internal_docs/TODO.md` sections 1–24, but `internal_docs/MANIFEST.md`
and the public `README.md` still implied the v0.0.x feature surface. This
milestone rewrites the doc-text only — no code, no examples, no docs site —
so the rest of v0.2.x can build on truthful baselines.

## Enhancements / Fixes

- Rewrite the "Implemented Features" and "Feature Gaps" sections of
  `internal_docs/MANIFEST.md`. Promote everything `TODO.md` marks DONE
  (sections 6–17, 18.1–18.14, 19, 20, 22, 23, 24) into Implemented Features.
  Trim Feature Gaps to genuinely outstanding items: custom slide layouts,
  transition/animation read access, cross-run text operations.
- Bump the version line at the top of `MANIFEST.md` from `0.0.01` to
  `0.1.0` so it tracks the package release.
- Move WordArt / preset text warp and text-level 3D into "Known Limitations
  — Decorative Effects (Out of Scope)" per `TODO.md` section 21.
- Refresh the `README.md` feature list to name everything shipped — pattern
  line fills, callouts, movies, z-order / visibility / lock-aspect, computed
  slide numbers, custom document properties, shadow-color transparency,
  expanded chart family list.
- Reshape the `dev_map/` roadmap: split the original v0.2.0 plan into this
  doc-text resync (now v0.2.0), the example-script gap (v0.2.1), and the
  docstring + Sphinx work (v0.2.2). Update `dev_map/README.md` status table
  to list the new sub-versions.

## Dependencies

- None on other versions. Lands on top of `v0.1.0`.

## Out of Scope for this Version

- New API surface. No public function/class additions in this milestone — if
  a doc audit surfaces a real API gap, file it for `v0.3.0`.
- New example scripts — deferred to `v0.2.1`.
- Docstring audit and Sphinx scaffold — deferred to `v0.2.2`.
- Changing internal architecture or refactoring code paths.

## Test Plan

- `pytest -q` remains green; no test count regression.
- `grep -n "0.0.01" internal_docs/MANIFEST.md` returns no matches.
- Spot-check: for every entry remaining in MANIFEST "Feature Gaps", a
  targeted `grep` in `src/pptx/` for the named XML element or attribute
  surfaces no meaningful implementation.
- For every commit in `git log v0.1.0..HEAD -- src/pptx/`, the headline
  feature is either reflected in MANIFEST "Implemented Features" or
  explicitly out of scope.
- `README.md` feature list and MANIFEST "Implemented Features" name the
  same capabilities — no item appears in one but not the other.
- `dev_map/README.md` status table lists `v0.2.0`, `v0.2.1`, `v0.2.2` with
  matching themes, and each milestone file follows `_TEMPLATE.md`.
