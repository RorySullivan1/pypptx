# v0.2.0 — Documentation & MANIFEST Resync

**Branch:** `v0.2.0`
**Previous:** `v0.1.0`
**Status:** Planned

## Objective

Bring the project's user-facing and internal documentation back in sync with
the actual implementation state. The codebase has shipped most of what
`internal_docs/MANIFEST.md` lists as "Feature Gaps" — but those docs (and the
public README) still imply minimal coverage. Resync them so new contributors
and downstream users can see what `pypptx` actually does today.

## Enhancements / Fixes

- Rewrite the "Feature Gaps" section of `internal_docs/MANIFEST.md` —
  promote shipped items (per `TODO.md` sections 1–24) into "Implemented
  Features" and trim the gap list to what is genuinely outstanding.
- Bump the version line at the top of `MANIFEST.md` (currently `0.0.01`).
- Update `README.md` feature list to reflect current capability (charts,
  effects, accessibility, 3D formatting, theme access, etc.).
- Add missing example scripts for under-demonstrated areas: trendlines /
  error bars, secondary axes round-trip, custom slide-master walk, comments
  + tags + sections, picture brightness / contrast / grayscale.
- Docstring audit of public API modules (`pptx/api.py`, `pptx/presentation.py`,
  `pptx/slide.py`, `pptx/shapes/`, `pptx/text/text.py`, `pptx/chart/chart.py`,
  `pptx/dml/`) — confirm every public property/method has a docstring with
  type hints visible.
- Generate a Sphinx scaffold under `docs/` (config + index + autodoc stubs) —
  no published site yet, just the buildable skeleton.

## Dependencies

- None on other versions. This is a documentation-first milestone that can
  start immediately on top of `v0.1.0`.

## Out of Scope for this Version

- New API surface. No public function/class additions in this milestone — if
  a docstring audit surfaces a real API gap, file it for `v0.3.0`.
- Publishing the docs site (RTD / Pages). Scaffold only; publishing belongs
  to `v1.0.0`.
- Changing internal architecture or refactoring code paths.

## Test Plan

- `pytest -q` remains green; no test count regression (delta only from
  example additions).
- Each new example script runs end-to-end and produces a `.pptx` that
  re-opens via `Presentation(...)`.
- Sphinx scaffold builds without warnings on the in-tree docstrings.
- Manual diff of `MANIFEST.md` against `TODO.md` shows zero contradictions.
